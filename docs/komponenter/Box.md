# Box

En tegnet ramme rundt innhold: kort, paneler, skjema, callout.

| Klasse | Bruk |
| --- | --- |
| `b-box` | Standard ramme på `paper`. |
| `b-box--raised` | `paper-2` og `shadow-lift`, for dialoger og ting som ligger oppå. |
| `b-box--flat` | Uten strek, bare `paper-2`. |
| `b-box--dashed` | Stiplet: et sted noe kan slippes eller legges til. |
| `b-callout` + `b-callout__mark` | Ramme med et stort tegn (`!`, `↳`) og én kort tekst. |

- Ikke legg bokser inni bokser mer enn ett nivå.
- Padding er `space-6`. Avstand mellom bokser i et rutenett er `space-8`.
