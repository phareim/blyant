# Table

Tabell med tegnet strek under hodet og stiplede rader. Raden under pekeren får et svakt tusjstrøk.

**Markup:** `<div class="b-table-wrap"><table class="b-table">…</table></div>`. Tall-kolonner får `class="num"` på både `th` og `td`.

- Hodet er `t-label` i Architects Daughter. Tallene står i tabulære sifre.
- Pakk alltid tabellen i `b-table-wrap`, så den ruller sidelengs på smale skjermer.
