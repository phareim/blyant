# Tag

Små merkelapper for status og kategori, pluss slektningene avatar, tast og fremdrift.

| Klasse | Bruk |
| --- | --- |
| `b-tag` | Nøytral merkelapp. |
| `b-tag--red/orange/yellow/green/blue/purple` | Støvet fyll. Legg `<span class="b-dot"></span>` foran når fargen er en status. |
| `b-tag--marker` | Det ene som er nytt eller anbefalt. |
| `b-avatar` | Initialer i en skjev sirkel. |
| `b-kbd` | Tast i en hurtigtast-forklaring. |
| `b-progress` | Fremdrift: `style="--value: 62%"` og et tomt `<i>` inni. Husk `role="progressbar"`. |

- Status har alltid et ord. Fargen alene sier ingenting.
